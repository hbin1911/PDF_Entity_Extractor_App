# AI-Powered PDF Entity Extractor App

## Overview
This project is an AI-powered PDF Entity Extractor application developed using Streamlit and Hugging Face transformer models. The application extracts entities such as person names, organizations, locations, dates, and email addresses from PDF documents.

## Features
- PDF upload
- Text extraction
- Named Entity Recognition (NER)
- Entity visualization
- CSV/JSON export
- CPU/GPU inference support

## Technologies Used
- Python
- Streamlit
- Hugging Face Transformers
- PyTorch
- pdfplumber
- Pandas

## Folder Structure
- app/ → Streamlit frontend
- models/ → AI models
- utils/ → backend modules
- data/ → PDFs and outputs
- tests/ → unit tests
